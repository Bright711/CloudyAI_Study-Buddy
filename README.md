# ☁️ CloudyAI Study Buddy
**Built for the #1MillionDevs Hackathon**

CloudyAI is an intelligent AZ-900 exam prep tool that doesn't just tell you when you're wrong—it teaches you *why* using grounded AI analogies and a "Misconception Radar."

## 🚀 Tech Stack
- **Frontend & API:** Next.js + TypeScript + Tailwind CSS
- **Database:** Supabase (PostgreSQL)
- **AI Integration:** Vercel AI SDK (Structured JSON output)
